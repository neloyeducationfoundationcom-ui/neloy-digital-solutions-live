# Neloy Digital Solutions — active Worker architecture

This map describes the repository after the local Stage 7–9 architecture commits. It is a source map, not permission to deploy or consolidate remaining wrappers. The current Worker entry is selected by `wrangler.toml` (`main = "src/worker.js"`). Cloudflare production changes only after a separately approved GitHub/deployment step.

## Request path and execution order

`src/worker.js` forwards `fetch(request, env, ctx)` to `whatsapp-lead-prefill-wrapper.js`. That wrapper starts an existing chain of root-level wrappers; each can handle a request or delegate inward. The important outer-to-inner sequence is:

1. `whatsapp-lead-prefill-wrapper.js` (favicon and WhatsApp prefill), `spam-shield-wrapper.js` (lead/chat abuse checks).
2. Public page and portfolio wrappers, including `organic-marketing-aeo-wrapper.js`, `creative-partner-aeo-wrapper.js`, `ranking-progress-wrapper.js`, `systeme-web-design-landing-wrapper.js`, and `video-indexing-aeo-wrapper.js`.
3. `seo-meta-cleanup-wrapper.js` (final metadata and `/llms.txt` override), `strict-security-wrapper.js` (outer request rules and response headers), `seo-aeo-offer-wrapper.js` (base indexing handlers, service content and schema), and `mobile-nav-wrapper.js` (footer and `/terms` selection).
4. More public page and media wrappers, `lead-cors-wrapper.js`, `security-hardening-wrapper.js` (inner security/CSP), `website-route-wrapper.js` (inner `/website` 302 rule), and `premium-redesign-worker.js` (base homepage, lead API and admin UI).

The actual import graph has additional wrappers between these named points. Branch imports, such as `terms-page-wrapper.js` and the image/sponsor helpers, are also part of the active graph. Do not flatten or reorder this chain just because a lower-level handler seems duplicated: outer wrappers determine the observed response.

## Protected route contract

The 19 GET routes in the local architecture comparison are `/`, `/showcase`, `/portfolio`, `/logo-design`, `/website-design`, `/social-media-design`, `/video-editing`, `/digital-marketing`, `/team`, `/terms`, `/website`, `/website/`, `/web-design-bangladesh`, `/web-design-bangladesh/`, `/robots.txt`, `/sitemap.xml`, `/llms.txt`, `/admin`, and `/terms/`. Both Bangladesh consultation paths return **301**; the other listed routes return **200** in the saved baseline. `/portfolio` uses the `/showcase` canonical. `/team`, `/terms`, `/website`, and `/website/` retain the observed root canonical where applicable. The public sitemap lists seven canonical URLs and video information.

The homepage form points at `/api/leads`; the uncredentialed local GET is **401**, the local OPTIONS preflight is **403**, and the admin interface is **200** with no-store/noindex protection. These checks do not inspect lead records. The checked images and videos under `/showcase-media/` return **200**.

## Remaining wrapper debt and handoff

Root-level wrappers in the configured import graph remain active even when their names or content appear historical. Separately, the root `worker.js`, `lead-admin-wrapper.js`, `mobile-wrapper.js`, `src/admin/page.js`, and several older image, testimonial, and style modules are not reachable by static imports from `src/worker.js`; this does not authorize deletion, because external uses or future migrations have not been ruled out. `README.md` previously described an older package and is updated to point to this map.

Stages 7–9 isolate indexing generators, the active consultation redirect, and security response headers. Stage 10 documents the current state without changing execution. Complete a combined 19-route old-versus-new status, complete Worker-header, and SHA-256 body comparison (plus redirects, `/admin`, preflight, and assets) before proposing production deployment; perform a separate read-only live comparison after deployment. The premium white, blue, deep navy, and restrained cyan redesign is a later phase with its own content/SEO and mobile checks.
